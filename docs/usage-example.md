# Practical Usage Example

A new contributor's first real contribution to this repository usually looks like:

```bash
git checkout -b docs/fix-typo
# edit docs/setup.md
git add docs/setup.md
git commit -m "docs(test-3): fix typo in setup guide"
git push origin docs/fix-typo
```

Then open a pull request describing the fix and, if it addresses one, link the related issue.
