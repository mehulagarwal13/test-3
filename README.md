# test-3

## Overview

`test-3` is a small example/test repository used to practice and verify real GitHub developer-onboarding workflows end to end: prerequisites, setup, running, testing, and contributing. It is intentionally minimal so a new contributor can read through it in a few minutes and understand the whole project.
